Conectar ao Supabase
Suas dailies ficam salvas na nuvem. Configure uma vez, acesse de qualquer dispositivo.
  1. Acesse supabase.com e crie uma conta gratuita
  2. Crie um novo projeto
  3. Vá em Settings → API e copie a Project URL e a chave anon public
  4. No SQL Editor, execute o script abaixo
  5. Cole as credenciais aqui e salve

Script SQL — execute no Supabase
create table if not exists dailies (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  date date not null,
  mood text, energia int,
  estudou text, estudo_min int,
  praticou text, aprendizado text, duvida text, amanha text,
  academia boolean, academia_min int,
  mba text,
  leitura text, leitura_pag int,
  lazer text,
  sono_h numeric, bloqueio text
);
alter table dailies enable row level security;
create policy "allow all" on dailies
  for all using (true) with check (true);
